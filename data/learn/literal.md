---

regex-এ বেশিরভাগ অক্ষর নিজের সাথেই মেলে। `a` মানে a, `5` মানে 5, `-` মানে -। বাংলা অক্ষরও তাই: `ঢাকা` লিখলে ঢাকা খোঁজে।

```regex
/ঢাকা/g
ঢাকা থেকে চট্টগ্রাম, আবার ঢাকা।
```

## বিশেষ চিহ্ন

এই চিহ্নগুলোর বিশেষ মানে আছে, তাই এগুলো নিজের সাথে মেলে না:

| চিহ্ন | কাজ (পরের পাঠগুলোতে) |
|---|---|
| `.` | যেকোনো অক্ষর |
| `*` `+` `?` `{ }` | কতবার |
| `^` `$` | শুরু আর শেষ |
| `[ ]` | অক্ষরের সেট |
| `( )` | group |
| `\` | escape |

আর আছে `|`, এর মানে "অথবা"।

## escape: `\`

বিশেষ চিহ্নকে সাধারণ অক্ষর হিসেবে খুঁজতে আগে `\` বসান। দাম লেখা `5.00` খুঁজতে `5\.00` লিখতে হয়। শুধু `5.00` লিখলে `.` যেকোনো অক্ষরে মিলবে, ফলে 5x00-ও মিলবে।

```regex
/5\.00/g
দাম 5.00 টাকা, ভুল লেখা 5x00
```

`\` মুছে দেখুন, 5x00-ও মিলে যাবে।

## মনে রাখুন

- সাধারণ অক্ষর নিজের সাথে মেলে।
- `. * + ? ^ $ ( ) [ ] { } | \` বিশেষ। আক্ষরিক খুঁজতে আগে `\` দিন।

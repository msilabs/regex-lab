title: "কতবার: + * ? { }"
order: 6
summary: আগের অক্ষর বা group কতবার আসবে তা বলে দেওয়া।
---

এখন পর্যন্ত প্রতিটা চিহ্ন একটা অক্ষরে মিলেছে। ১১ অঙ্কের নম্বর মেলাতে `\d` ১১ বার লেখার দরকার নেই। চিহ্নের **পরে** quantifier বসান:

| লিখুন | মানে |
|---|---|
| `+` | ১ বা তার বেশি |
| `*` | ০ বা তার বেশি |
| `?` | ০ বা ১ (থাকতেও পারে, না-ও পারে) |
| `{3}` | ঠিক ৩ বার |
| `{3,5}` | ৩ থেকে ৫ বার |
| `{3,}` | অন্তত ৩ বার |

```regex
/\d+/g
ঘর 7, রুম 42, সাল 2026
```

এবার প্রতিটা পুরো সংখ্যা এক টুকরো হয়ে মিলেছে।

## ঠিক কতগুলো

```regex
/01[3-9]\d{8}/g
01712345678 0171234567 01812345678
```

মাঝেরটায় শেষে ৮টা না, ৭টা অঙ্ক। তাই মেলেনি।

## থাকতেও পারে: `?`

`colou?r` মানে u থাকতেও পারে, না-ও পারে।

```regex
/colou?r/g
color colour colouur
```

## quantifier শুধু ঠিক আগের জিনিসের ওপর

`ab+` মানে a, তারপর এক বা একাধিক b। পুরো `ab` বারবার চাইলে group লাগে: `(ab)+`। group পরে আসছে।

```regex
/ab+/g
ab abbb abab
```

## মনে রাখুন

- quantifier বসে অক্ষরের **পরে**, আর শুধু ঠিক আগের জিনিসে কাজ করে।
- `+` ১+, `*` ০+, `?` ০ বা ১, `{n,m}` নির্দিষ্ট সংখ্যা।

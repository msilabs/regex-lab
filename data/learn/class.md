`[ ]`-এর ভেতরে যা লিখবেন, তার **যেকোনো একটা** অক্ষর মিলবে। `[ae]` মানে a অথবা e, একটা অক্ষর।

```regex
/gr[ae]y/g
gray grey groy graey
```

graey মেলেনি, কারণ `[ae]` একটাই অক্ষরে মেলে, দুটো না।

## range: `-`

পরপর অক্ষর লিখতে `-` দিয়ে range বানান:

| লিখুন | মানে |
|---|---|
| `[0-9]` | যেকোনো একটা সংখ্যা |
| `[a-z]` | ছোট হাতের ইংরেজি অক্ষর |
| `[A-Za-z]` | ছোট বা বড় হাতের অক্ষর |
| `[০-৯]` | বাংলা সংখ্যা |
| `[3-9]` | 3 থেকে 9 |

বাংলাদেশি মোবাইল নম্বরের তৃতীয় অঙ্ক 3 থেকে 9 হয়, তাই `01[3-9]`:

```regex
/01[3-9]/g
017 019 013 012 010
```

## বাদ দেওয়া অক্ষর: `[^ ]`

বন্ধনীর ঠিক শুরুতে `^` দিলে মানে উল্টে যায়: **এগুলো ছাড়া** যেকোনো অক্ষর।

```regex
/[^0-9 ]/g
ঘর 12, রুম 7B
```

সংখ্যা আর ফাঁকা জায়গা ছাড়া সব মিলেছে।

## বন্ধনীর ভেতরে বিশেষ চিহ্ন

`[ ]`-এর ভেতরে `.` বা `*` সাধারণ অক্ষর হয়ে যায়। `[.]` মানে আক্ষরিক ডট। শুধু `]`, `\`, শুরুর `^` আর মাঝের `-` সাবধানে লিখতে হয়। `-` আক্ষরিক চাইলে একদম শেষে দিন: `[a-z-]`।

## মনে রাখুন

- `[abc]` = a, b বা c-এর একটা।
- `[a-z]` = range। `[^abc]` = এগুলো ছাড়া।

বাংলা নিয়ে regex লিখতে কয়েকটা জিনিস জানা দরকার, না হলে অবাক করা ফল আসবে।

## বাংলা অক্ষর: Unicode range

কম্পিউটারে প্রতিটা অক্ষরের একটা নম্বর আছে। বাংলার সব অক্ষর `\u0980` থেকে `\u09FF` এর মধ্যে। তাই `[\u0980-\u09FF]` মানে যেকোনো একটা বাংলা অক্ষর।

```regex
/[\u0980-\u09FF]+/g
Hello বাংলা world ভাষা
```

## আরও পরিষ্কার: `\p{Script=Bengali}`

`u` flag দিলে লিপির নাম দিয়ে লেখা যায়।

```regex
/\p{Script=Bengali}+/gu
Hello বাংলা world ভাষা
```

## বাংলা সংখ্যা

`\d` বাংলা সংখ্যায় মেলে না। `[০-৯]` লিখুন। দুটোই চাইলে `[0-9০-৯]`।

```regex
/[0-9০-৯]+/g
ইংরেজি 2026, বাংলা ২০২৬
```

## যুক্তাক্ষর আর কারচিহ্ন

চোখে যা একটা অক্ষর, ভেতরে তা কয়েকটা হতে পারে। "ক্ষ" আসলে তিনটা: ক, ্ (হসন্ত), ষ। "কি"-তে দুটো: ক আর ি।

```regex
/^.$/
ক্ষ
```

একটা `.` দিয়ে "ক্ষ" মেলেনি, কারণ এটা তিনটা অক্ষর। `.` বদলে `.{3}` লিখে দেখুন।

তাই বাংলায় "ঠিক ৫ অক্ষরের নাম" ধরনের নিয়ম regex দিয়ে ঠিকমতো লেখা কঠিন।

## PHP-তে `u` লাগবেই

PHP-তে বাংলা থাকলে pattern-এর শেষে অবশ্যই `u` দিন: `/[\x{0980}-\x{09FF}]+/u`। না দিলে PHP অক্ষরকে ভেঙে বাইট হিসেবে দেখে, ফল ভুল আসে।

## মনে রাখুন

- বাংলা অক্ষর: `[\u0980-\u09FF]` বা `u` flag সহ `\p{Script=Bengali}`।
- বাংলা সংখ্যা: `[০-৯]`।
- যুক্তাক্ষর একাধিক অক্ষর দিয়ে তৈরি।
